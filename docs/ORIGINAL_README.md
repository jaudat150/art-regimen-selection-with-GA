# نظام تحسين بروتوكولات علاج فيروس نقص المناعة البشرية (HIV) باستخدام الخوارزميات الوراثية

## الملخص التنفيذي

هذا المشروع يقدم نظاماً متقدماً لتحسين بروتوكولات علاج فيروس نقص المناعة البشرية (HIV) باستخدام الخوارزميات الوراثية (Genetic Algorithms). النظام مصمم خصيصاً للعمل في البيئات محدودة الموارد مثل سوريا، ويوفر تحسيناً متعدد الأهداف يشمل الفعالية السريرية، التكلفة، السمية، والالتزام بالعلاج. النظام متوافق مع إرشادات منظمة الصحة العالمية (WHO) لعام 2024 ويولد تقارير سريرية احترافية بصيغتي Excel والنص.

**النتائج الرئيسية:**

- نظام متكامل لتحسين بروتوكولات العلاج بناءً على الملف الشخصي السريري للمريض
- دعم كامل لمقاومة الأدوية والقيود السريرية
- تحسين متعدد الأهداف (الفعالية، التكلفة، السمية، الالتزام)
- تقارير سريرية احترافية قابلة للطباعة

---

## 1. المقدمة

### 1.1 خلفية المشكلة

علاج فيروس نقص المناعة البشرية (HIV) يتطلب بروتوكولات معقدة تجمع بين عدة أدوية من فئات مختلفة. التحديات الرئيسية تشمل:

1. **مقاومة الأدوية**: الطفرات الفيروسية تقلل فعالية الأدوية
2. **القيود السريرية**: الحساسية، ضعف وظائف الأعضاء، الحمل
3. **القيود الاقتصادية**: التكلفة العالية للأدوية في البلدان محدودة الموارد
4. **الالتزام بالعلاج**: الآثار الجانبية تؤثر على الالتزام طويل الأمد

### 1.2 الهدف من المشروع

يهدف هذا المشروع إلى تطوير نظام ذكي يساعد الأطباء في اختيار أفضل بروتوكول علاجي لكل مريض بناءً على:

- الملف الشخصي السريري (الطفرات، وظائف الأعضاء، الحساسيات)
- القيود الاقتصادية (حساسية التكلفة)
- إرشادات منظمة الصحة العالمية
- توفر الأدوية محلياً

### 1.3 أهمية المشروع

- **للمرضى**: تحسين النتائج السريرية وتقليل التكلفة
- **للأطباء**: أداة دعم قرار سريري موثوقة
- **للأنظمة الصحية**: تحسين تخصيص الموارد في البيئات محدودة الموارد

## 2. مراجعة الأدبيات

### 2.1 بروتوكولات علاج HIV

وفقاً لإرشادات منظمة الصحة العالمية 2024، البروتوكول المفضل يتكون من:

- **2 NRTI** (مثبطات إنزيم النسخ العكسي النوكليوزيدية) كعمود فقري
- **1 دواء ثالث** من فئة INSTI (مفضل) أو NNRTI أو PI

### 2.2 الخوارزميات الوراثية في الطب

الخوارزميات الوراثية أثبتت فعاليتها في:

- تحسين بروتوكولات العلاج المعقدة
- حل مشاكل متعددة الأهداف
- التعامل مع قيود متعددة

### 2.3 النماذج السريرية

النظام يستخدم نماذج سريرية قائمة على الأدلة:

- **مقاومة الأدوية**: بناءً على قاعدة بيانات Stanford HIVDB
- **السمية**: تضخم السمية عند ضعف وظائف الأعضاء
- **الالتزام**: تأثير الآثار الجانبية على الالتزام بالعلاج

### 3.2 تمثيل الحل (Individual Representation)

```python
{
    'primary_regimen': ['TDF', '3TC', 'DTG'],   # البروتوكول الأمثل
    'backup_regimen': ['TDF', '3TC', 'EFV']     # البديل الاقتصادي

```

**المبررات السريرية:**

- **البروتوكول الأساسي**: للفعالية والسلامة المثلى
- **البروتوكول الاحتياطي**: للبيئات محدودة الموارد أو مشاكل السمية
- **استقرار العمود الفقري**: البروتوكول الاحتياطي يستخدم نفس NRTIs لتجنب مقاومة متقاطعة

### 3.3 دالة اللياقة (Fitness Function)

دالة اللياقة متعددة الأهداف وتتكيف مع ملف المريض الشخصي:

```
Fitness = (متوسط_الفعالية × وزن_الفعالية) 
         - (مجموع_السمية × وزن_السمية) 
         - (التكلفة × وزن_التكلفة) 
         - (عبء_الآثار_الجانبية × وزن_الآثار_الجانبية)
         + (مكافأة_الامتثال_WHO إذا كان متوافقاً)
```

**الأوزان الأساسية:**
- **الفعالية**: 50.0 (الهدف الأساسي - قمع الفيروس)
- **السمية**: 30.0 (تجنب التوقف عن العلاج)
- **الآثار الجانبية**: 20.0 (تأثير على الالتزام)
- **مكافأة WHO**: 50.0 (حافز للبروتوكولات الموصى بها)

**التعديلات الشخصية حسب المريض:**
- **ضعف وظائف الأعضاء**: زيادة وزن السمية ×1.5
- **الأمراض المصاحبة**: زيادة وزن الآثار الجانبية ×1.2
- **عدد الطفرات > 2**: زيادة وزن الفعالية ×1.2
- **حساسية التكلفة**: مضاعف التكلفة (عالية: ×2.0، متوسطة: ×1.0، منخفضة: ×0.3)

**مكونات التقييم التفصيلية:**

1. **الفعالية**: متوسط الفعالية مع مراعاة المقاومة (يُرفض إذا < 75%)
2. **السمية**: مجموع السمية مع تضخيم حسب وظائف الأعضاء (×2 إذا تجاوز التأثير الوظيفة)
3. **التكلفة**: التكلفة الشهرية مرجحة بحساسية المريض
4. **الآثار الجانبية**: تأثير على الالتزام (الأرق، الدوار، الاكتئاب، إلخ)
5. **الامتثال لـ WHO**: مكافأة إضافية للبروتوكولات المعتمدة

**التطبيع**: النتيجة تُحول إلى نطاق 1-100 باستخدام دالة Sigmoid لسهولة التفسير السريري.

### 3.4 الخوارزمية الوراثية

#### 3.4.1 المعاملات

- **حجم السكان**: 60 فرداً
- **عدد الأجيال**: 100 جيل
- **احتمالية التهجين**: 70%
- **احتمالية الطفرة**: 30%
- **الانتخاب**: بطولة (حجم 3)

#### 3.4.2 المشغلين (Operators)

**1. التهجين (Crossover):**

- يتبادل فقط الدواء الثالث بين البروتوكولات
- يحافظ على استقرار عمود NRTI الفقري
- يتحقق من السلامة السريرية بعد التهجين

**2. الطفرة (Mutation):**

- تستبدل الدواء الثالث بدواء آمن بديل
- معايير الاختيار:
  - آمن للمريض (موانع، وظائف الأعضاء)
  - فعالية ≥ 90% من الدواء الحالي
  - تكلفة أقل أو سمية أقل (حسب أولويات المريض)

**3. الانتخاب (Selection):**

- بطولة (Tournament Selection) بحجم 3
- أكثر قوة من عجلة الحظ في المجموعات الصغيرة

### 3.5 القواعد السريرية

#### 3.5.1 السلامة الدوائية

```python
def is_drug_safe_for_patient(drug, profile, drug_data):
    # 1. الحساسيات (موانع مطلقة)
    if drug in profile['Allergies']:
        return False
  
    # 2. الحمل (EFV يسبب عيوب الأنبوب العصبي)
    if profile['Pregnancy'] and 'pregnancy' in contraindications:
        return False
  
    # 3. وظائف الكلى (TDF يتراكم في القصور الكلوي)
    if kidney_function < 0.3 and 'severe_renal' in contraindications:
        return False
  
    # 4. وظائف الكبد (NVP يسبب سمية كبدية)
    if liver_function < 0.4 and 'severe_hepatic' in contraindications:
        return False
  
    # 5. هامش الأمان (80% من وظيفة العضو)
    if drug_impact > organ_function * 0.8:
        return False
```

#### 3.5.2 الفعالية المعدلة للمقاومة

```python
def get_efficacy_with_resistance(drug, profile, drug_data):
    base_efficacy = drug_data[drug]['Efficacy']
    resistance_map = drug_data[drug]['Resistance_Reduction']
  
    total_reduction = sum(
        resistance_map[mutation] 
        for mutation in profile['Mutations']
        if mutation in resistance_map
    )
  
    adjusted = base_efficacy * (1.0 - min(total_reduction, 1.0))
    return max(0.0, adjusted)
```

**مثال:**

- مريض مع طفرة M184V → فعالية 3TC تقل بنسبة 90%
- فعالية أساسية 0.88 → فعالية معدلة 0.088

#### 3.5.3 الامتثال لإرشادات WHO

```python
def is_regimen_who_compliant(regimen, drug_data):
    # يجب أن يكون: 2 NRTI + 1 من [INSTI, NNRTI, PI]
    classes = [drug_data[d]['Class'] for d in regimen]
    return (
        classes.count('NRTI') == 2 and
        len([c for c in classes if c != 'NRTI']) == 1 and
        third_class in ['INSTI', 'NNRTI', 'PI']
    )
```

## 4. النتائج

### 4.1 أمثلة على البروتوكولات المولدة

**مثال 1: مريض HIV-SY-001**

- **الطفرات**: M184V, K103N
- **وظائف الأعضاء**: كبد 0.70، كلى 0.85
- **المراضات المشتركة**: التهاب الكبد B، اكتئاب
- **البروتوكول الأساسي**: TDF, 3TC, DTG
- **التكلفة**: $45.5/شهر (682,500 SYP)
- **البروتوكول الاحتياطي**: TDF, 3TC, EFV
- **التكلفة**: $15.5/شهر (232,500 SYP)
- **متوافق مع WHO**: ✓ نعم

### 4.2 تحليل الأداء

- **وقت التحسين**: ~1-2 دقيقة لكل مريض (100 جيل)
- **التقارب**: النظام يتقارب عادة في 60-80 جيل
- **الاستقرار**: جميع البروتوكولات المولدة صالحة سريرياً

### 4.3 معالجة الحالات الحدية

النظام يتعامل مع:

- **مقاومة متعددة الأدوية**: يختار أدوية بفعالية معدلة عالية
- **عدم توفر NRTIs آمنة**: يولد بروتوكول احتياطي
- **قيود التكلفة العالية**: يفضل البروتوكول الاحتياطي

## 5. المناقشة

### 5.1 نقاط القوة

1. **التصميم السريري**: جميع القواعد مبنية على أدلة سريرية
2. **المرونة**: يدعم قيود متعددة (تكلفة، توفر، سلامة)
3. **سهولة الاستخدام**: واجهة Excel مألوفة للأطباء
4. **الموثوقية**: لا يولد بروتوكولات غير آمنة
5. **الملاءمة للبيئات محدودة الموارد**: مصمم خصيصاً لسوريا

### 5.2 القيود

1. **نموذج المقاومة المبسط**: لا يغطي جميع التفاعلات بين الطفرات
2. **البيانات الثابتة**: التكلفة والتوفر يحتاجان تحديث دوري
3. **عدم وجود تحقق سريري**: يحتاج التحقق من النتائج في الممارسة السريرية
4. **القيود الحسابية**: قد يكون بطيئاً على أجهزة قديمة جداً

### 5.3 التحسينات المستقبلية

1. **تحسين نماذج المقاومة**: تطوير خوارزميات أكثر دقة للتنبؤ بالمقاومة
2. **واجهة ويب**: لتسهيل الوصول
3. **قاعدة بيانات سريرية**: لتتبع النتائج طويلة الأمد
4. **دعم بروتوكولات متعددة**: لعلاج TB/HIV المشترك
5. **تحسينات الأداء**: خوارزميات متوازية للأجهزة المتعددة النوى
